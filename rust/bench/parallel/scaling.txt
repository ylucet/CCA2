# Machine-scaling and batch measurements for PARALLEL.md. Frances (2 x Xeon Gold 6426Y, 32 cores,
# 64 hardware threads, 2 NUMA nodes, 251 GB), 2026-11-14, SHARED machine (load 1-3 from other jobs
# before each run). Wall-clock seconds; where several repetitions were made they are all listed.
# Single timings on this machine scatter by up to 20% (two modes, e.g. 1.6 s and 1.9 s for fixture
# 200), so read the minima and the ratios.

## 1. One call of fixture 196 (kink, biconjQ -> AlgCrv, 317 faces), clean build
main thread, process never had a second thread      7.896  7.910  8.283  7.929
main thread, an idle second thread exists           9.444  9.687  10.715
on a worker thread (parbench 1 copies 196)          9.400  9.828  9.406  9.738
on a worker thread, MALLOC_ARENA_MAX=1              9.353  9.867  9.359  9.671
on a worker thread, pinned to one core (taskset)    9.827  9.401  9.388
-> the "thread tax": about +20% on this allocation-heavy call as soon as the process is
   multi-threaded (glibc 2.35 malloc leaves its single-thread fast path). Fixture 200: not visible.
